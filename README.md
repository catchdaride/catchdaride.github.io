# catchdaride.github.io 🚌

> Dedicated frontend gateway for **Catch Da Ride!** (Public Transit Explorer)  
> Hosted on GitHub Pages: [https://catchdaride.github.io/](https://catchdaride.github.io/)

This directory and its counterpart repository (`catchdaride/catchdaride.github.io`) serve as the branded public gateway with:
- HTTPS delivery on custom/GitHub domains
- Full-viewport responsive iframe container (100dvh)
- Device geolocation permission pass-through
- Open Graph social media sharing cards (WhatsApp, iMessage, Telegram, Twitter)
- Cache-busting synchronization with PythonAnywhere production backend (`https://geohoo.pythonanywhere.com/`)
